# Local pilot results

Measured subset results, not final manuscript evidence. See run_manifest.json in the parent run directory for architecture and data provenance. A0-A6 here are pilot analogues. Metrics use fake as the positive class; p_real stores P(real). Tables contain sample SD across training seeds. Bootstrap CIs are conditional on each fitted seed, clustered by exact image hash when available. McNemar p-values are nominal post-level checks and should not support significance claims when posts share images/events.

Empty contextual subsets have no rows; missing evidence is never reported as measured retrieval quality. See report_manifest.json for unmeasured outputs and limitations.
